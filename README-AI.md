# دمج Claude مع مهامي

## 1) تثبيت الخادم
افتح مجلد الخادم ثم:

```bash
npm install
```

## 2) المفتاح السري
انسخ `.env.example` إلى `.env`، ثم ضع مفتاح Anthropic داخل:

`ANTHROPIC_API_KEY=...`

لا تضع هذا المفتاح داخل `index.html` ولا GitHub Pages.

ضع `SESSION_SECRET` عشوائيًا طويلًا (32 حرفًا أو أكثر).

## 3) تشغيل الخادم

```bash
npm start
```

سيعمل افتراضيًا على:

`http://localhost:3000`

وللفحص:

`GET /api/health`

## 4) ربط صفحة مهامي بالخادم
الملف `index.html` يستخدم افتراضيًا:

`http://localhost:3000`

وعند النشر يمكن وضع:

```html
<script>window.MAHAMI_API_BASE_URL='https://YOUR-SERVER-DOMAIN';</script>
```

قبل سكربت التطبيق الرئيسي.

## 5) الملفات التي يدعمها المساعد
- صورة: PNG / JPEG / GIF / WebP
- PDF حتى 8MB

المساعد يقرأ المرفق على السيرفر ويرسله إلى Claude، والمفتاح يبقى في السيرفر.

## 6) الأفعال
المساعد يستطيع طلب:
- إضافة مهمة
- عرض مهام اليوم وبيانات الإحصائيات
- إكمال مهمة
- إضافة ملاحظة
- تسجيل مصروف
- حذف مهمة أو ملاحظة بعد تأكيد الطالب

البيانات المستخدمة هي بيانات الطالب الحالية التي يرسلها التطبيق، ولا يخزن السيرفر بيانات التطبيق نفسها.

## 7) وضع التركيز وتطوير العقارات
واجهة وضع التركيز أصبحت نظام بناء متدرجًا داخل التطبيق:
- 5 مشاريع مستقلة: بيت عصري، فيلا فاخرة، قصر ملكي، استراحة ريفية، مبنى تجاري.
- لكل مشروع تقدمه الخاص المحفوظ في بيانات مهامي.
- 7 مستويات متدرجة: الأساس والأرض، بيت صغير/كوخ، شقة/مبنى سكني، عمارة كاملة، فيلا فاخرة، قصر، قلعة حصينة.
- كل جلسة تركيز مكتملة تضيف دقائق إلى المشروع المحدد وتحدّث المستوى والمشهد تلقائيًا.
- المشهد ثلاثي الأبعاد قابل للدوران 360 درجة بالسحب، مع دوران تلقائي وإضاءة وظلال.
- أزيلت عناصر المواعيد القديمة من نافذة التركيز وأصبحت النافذة مخصصة للبناء والتقدم.

حدود الترقية الحالية للمستويات هي: 0، 60، 180، 360، 600، 900، 1200 دقيقة تركيز تراكمية لكل مشروع.
